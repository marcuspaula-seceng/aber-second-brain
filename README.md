# ABER Second Brain | AI Life

ABER is a personal inbox for tasks and ideas. Capture what's on your mind, turn ideas into tasks, and choose up to three priorities for today.

## Getting started

Open `index.html` in a modern browser or serve it from any static HTTPS host. ABER requires no account, installation, or external dependencies.

1. Save a task or idea in one of six areas.
2. Add a due date and set its importance when useful.
3. In **Today**, review the suggestions and pick up to three tasks yourself.
4. Select **Copy summary** to copy today's list.
5. Complete a task to remove it from the summary. Reopen it from the inbox if needed.

Manual picks come first. Suggestions fill the remaining slots with open tasks that are due today, overdue, or have no due date. Tasks with the same due date are ordered by importance, then by capture time. Ideas become eligible when converted to tasks.

## Data storage

ABER saves entries in your browser's local storage. The application has no backend, tracking, or external scripts. It copies the summary to your clipboard only when you ask it to.

Use the same browser profile and site address to find your entries again. A different browser profile or site address starts with a separate inbox. Clearing site data may erase your entries.
